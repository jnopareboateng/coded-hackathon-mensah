# Instructions

Welcome to the AI Fashion Retail Hackathon! We're excited to see how you blend style and technology. This document contains all the instructions you need to build a standout fashion e-commerce experience.

## 🏆 Evaluation Criteria

Your project will be judged rigorously on the following five pillars. Keep these in mind throughout your development process:

1. **UI (User Interface) & Design:** Does the platform have the "look and feel" of a premium fashion website? Is it aesthetically pleasing, responsive, and intuitive?
2. **Functionality:** Does the application work as intended? Are all required features (inventory, checkout, campaigns) operational?
3. **Testing:** Is the application robust? Have edge cases been considered and handled gracefully?
4. **Data Integrity:** Does the application correctly interact with the provided backend? Is data accurately displayed, submitted, and managed?
5. **Commercial Viability:** Could this product be used by a real business today? Does the user journey make sense for e-commerce?

## 🛠️ The Challenge Tasks

The hackathon is divided into two main components: Planning and Development. You are free to tackle the development phase (Frontend vs. Backend first) in whichever order suits your workflow best.

### Task 1: User Flow & Architecture (Miro)

Before writing code, you need to map out the user journey and system flow. You have two options for completing this task:

**Option A: Manual Flow Creation**

1. Create a free account on [Miro.com](https://miro.com/).
2. Design a comprehensive flowchart on a Miro board detailing the user journey (from browsing to WhatsApp checkout) and the backend data interactions.

**Option B: LLM Assisted Flow**

1. Use Claude (or your favorite LLM) to generate the logic and structure for your user flow.
2. *Note: Ensure you can clearly explain and present the flow generated by the LLM.*

### Task 2: Building the Application (Frontend & Backend Integration)

This is the core building phase. You will be building a fashion e-commerce interface and connecting it to our provided backend API.

**Development Flexibility:** You can build the frontend first and plug in the API later, or set up your API calls first and build the UI around them. The choice is yours.

**The Backend API & Documentation:** You are required to use the provided API to power your application. 🔗 [**API Documentation & Endpoint Access**](https://api-hackathon.codedematrixtech.com/)

**Required API Integrations:** Your application must successfully utilize the API to perform the following core functions(feel free to add any if you want to):

- **Inventory Management:** Fetch and display products. *(Note: Product images for the inventory are provided within the API documentation resources).*
- **WhatsApp Checkout:** Implement a seamless checkout flow that integrates with WhatsApp as outlined in the API docs.
- **Campaigns:** Fetch and display active marketing campaigns or promotions.
